## 1. What this is
Tritorc App — mobile-first PWA for Tritorc (industrial bolting, on-site machining, pipeline integrity).
Prototype stage. Repo: `tritorc-ai/...`, branch flow: feature branch → PR → `main` (current: `ui-updated`).

## 2. Stack
- Next.js **16.3** (App Router; breaking changes vs. older Next — check `node_modules/next/dist/docs/` before using unfamiliar APIs, per AGENTS.md), React 19.2, TypeScript
- Tailwind CSS 4 (`app/globals.css`, theme tokens: brand-red, graphite, ivory, cu, ink…), shadcn/ui + Radix (`components/ui/`), lucide-react
- Fonts in `lib/fonts.ts`: Plus Jakarta Sans (Company/Library), Chakra Petch + Anybody (splash)
- Content: Strapi CMS (`cms.tritorc.com`) via `lib/strapi.ts` + `lib/strapiClient.ts`; mock fallback in `lib/mock/*`
- PWA: `app/manifest.ts`, `public/sw.js`, `ServiceWorkerRegister`
- Scripts: `npm run dev | build | lint`. No test suite.

## 3. Structure
```
app/
  layout.tsx        root: metadata, viewport, Splash, BottomNav, SW register
  template.tsx      page transition wrapper
  page.tsx          Home
  products/         page (catalogue) · [slug] product detail · c/[slug] category
  services/         page · [slug] service detail
  company/ library/ events/(+[slug]) notifications/
  **/loading.tsx    skeleton screens per route
components/
  app/       app-level screens/widgets (BottomNav, Splash, Hero, Product/Service DetailView,
             LibraryView, NotificationFeed, EnquiryForm, Carousel variants, Pdf/Media modals…)
  home/      HeroCarousel, EventTicker, sections
  company/   CoreValues, PhotoSlideshow, RotatingLines
  products/  scroll track / showcase cards / category cards
  ui/        shadcn primitives
lib/
  strapi.ts        single seam to CMS (server-only)
  mock/            appContent, content, events, images, imageFallbacks, videos
```

## 4. Key decisions (keep; add new ones with date)
- **Single CMS seam** (`lib/strapi.ts`): only *catalogues* are live from Strapi; stats, case studies,
  certifications, journey, services, products, testimonials still return mock data until their
  content types are populated. Swap one function at a time.
- **Mobile-app feel:** bottom nav, splash on startup (guarded by `splashGuard.ts`), safe-area insets,
  standalone PWA display.
- **Palette:** app uses grey/black (neutral) palette; events & notifications were recently aligned to it.
  manifest theme `#171717`, viewport themeColor `#f3f3f2`. The Tritorc wordmark is always shown in its brand red (#d42427), including the Home header, and the app icon is that logo's T in red on white (2026-10-31).
- **Images:** remote allowed only from tritorc S3 media bucket, cms.tritorc.com, (www.)tritorc.com
  (`next.config.ts`). Local fallbacks in `lib/mock/imageFallbacks.ts`.
- **Site URL:** `NEXT_PUBLIC_SITE_URL` → Vercel env → localhost, used for `metadataBase`.
- Detail pages (product/service) were redesigned (PR #6); home has stacked swipeable event notifications.

## 4c. Content CMS (own Strapi in `cms/`) - branch `new-strapi`
- Why: access to the shared `cms.tritorc.com` is held by someone else (token returned 401), so the app gets its **own content Strapi 5** at `cms/` (separate from `tritorc-strapi` = notifications/enquiries). Default port **1338** (`tritorc-strapi` uses 1337).
- 14 content types as code in `cms/src/api/*` (Draft & Publish on): product-section, product-category, product, service-section, service, case-study, testimonial, certification, journey-milestone, impact-stat, core-value, global-office, event, brand. `cms/scripts/seed.js` loads them from `cms/scripts/seed-data.json` (exported from `lib/mock/content.ts`/`events.ts`) and creates the read-only token `tritorc-app`; safe to re-run.

Defaults for those pages live in `lib/mock/siteContent.ts`. Images: each has an `image` upload field and an `imageUrl` text field (local /public path); the upload wins. Still in code: notifications (teammates' Strapi), the home ticker and industries list.
- Images: unchanged convention - caption `product:<slug>:thumbnail|hero|gallery:product|gallery:in-use` (`service:` likewise); `directImageUrl` text field keeps existing remote photos working. No code change needed to add photos later.
- Env (Next `.env.local`): `STRAPI_API_URL=http://localhost:1338` + `STRAPI_API_READ_TOKEN` (seed script writes both). Run CMS: `powershell -File cms/start-dev.ps1`. Notes: `cms/TRITORC-NOTES.md`.
- **Notifications merged in (2026-10-26):** decision made to run ONE Strapi (this one) for content, notifications, push subscriptions and enquiries; `tritorc-strapi` is retired once Vinay/Iqra are told. Their old dev data (if any) was not migrated: it was test data on a dev SQLite file on another PC. Real device push still needs a test on a phone (HTTPS or localhost, iOS needs Add to Home Screen).

## 7. Gotchas
- Windows dev machine; git warns LF→CRLF on edits (harmless).
- ffmpeg was installed on the js94 machine with `winget install Gyan.FFmpeg` (2026-10-24, to read a tutorial video); new shells have it on PATH, older ones need the full path under `%LOCALAPPDATA%\Microsoft\WinGet\Packages\Gyan.FFmpeg_*`. `drawtext` needs `fontfile='C\:/Windows/Fonts/arial.ttf'`.
- `lib/strapi.ts` is `server-only` — don't import from client components.
- Windows: Strapi's admin build can fail with swc "Failed to load native binding" when a drive root lets all users replace files; `cms/start-dev.ps1` works around it with a temporary drive letter. SQLite allows one writer: stop Strapi before `node cms/scripts/seed.js`.
